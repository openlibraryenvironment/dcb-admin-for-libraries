# Welcome to DCB Admin for Libraries

## What is DCB Admin for Libraries?

DCB Admin for Libraries is part of the OpenRS DCB suite of applications. It is a modern web app, built for library staff within OpenRS consortia. It provides library staff a portal into their OpenRS resource sharing experience, facilitating circulation reports, staff and walk-up requesting, amongst other functionality.

DCB Admin for Libraries is built as a React SPA, using Vite as build tooling, Material UI for a component framework, and react-query and TanStack Router. Testing is handled by Vitest and Playwright.

## Accessibility
DCB Admin for Libraries is built to comply with the WCAG 2.2 AA accessibility standard. You can find our VPAT [here](docs/DCB_Admin_for_Libraries_VPAT.md).

## What is OpenRS?
OpenRS is an open-source resource sharing initiative that is reinventing resource sharing to meet the needs of different types of consortia. DCB Admin for Libraries is part of the OpenRS suite, developed by [Knowledge Integration](https://www.k-int.com/).

Interested in OpenRS? You can find out more on the [official website](https://openrs.org/).
